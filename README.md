# Etch Content Hub Sort

Adds search, sorting, pagination, hierarchical browsing, quick editing of parent and status, item creation, and WordPress Trash actions to the Etch Content Hub. Etch 1.7.0 is the tested integration point. Install and usage details are in [readme.txt](readme.txt).

## Development

Update the `Version` header and `Stable tag` in `readme.txt` together when preparing a new release. Test against the current Etch interface before packaging an installable ZIP. This repository does not configure GitHub-based WordPress updates.

The PHP, JavaScript, and CSS are GPLv3-or-later. The SVG icons were supplied by the site owner; confirm their redistribution terms before making the repository public.
