## Content Explorer for Etch 2.1.0

Choose which editor shortcuts appear for each post type in **Settings > Editors**. Use both editors for Pages, WordPress only for Articles and Events, or set a different combination for your site. List and maps follow the same explicit choices. Patterns, Etch components, templates, and template parts keep both shortcuts where available.

Settings transfer includes editor choices. Existing WordPress permissions and Etch document support still apply.

Settings open in a floating panel beside the left menu. The collapsed menu keeps its icons available, with tooltips on hover and keyboard focus.

**General > Appearance > Text size** lets you increase Content Explorer text up to 200% and remembers the choice in your browser.

The Site map batches taxonomy lookups and loads posts and terms in parallel. It uses a steady ring for the current item and keeps the surrounding graph steady as the pointer moves across nodes.
